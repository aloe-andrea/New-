Countdown, quote and picture on your Home Screen and Lock Screen.

  1. Install Scriptable from the App Store (free).
  2. Tap the button above to copy the script.
  3. Open Scriptable, tap +, paste, then tap the title at the top and name it Time. Tap Done.
  4. Tap the script once to see a preview and allow network access if asked.
  5. Home Screen: long-press an empty spot, Edit, Add Widget, choose Scriptable, pick a size, add it. Long-press the new widget, Edit Widget, set Script to Time.
  6. Lock Screen: long-press the Lock Screen, Customize, Lock Screen, tap the widget area, add Scriptable, then tap it and set Script to Time.
